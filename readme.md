# Controle de Níveis de Água

Este projeto consiste em um sistema simples de monitoramento de um reservatório de água executado no terminal. O programa exibe mensagens de alerta com cores personalizadas para cada nível do reservatório, utilizando a biblioteca externa **colorama**.

## 🚀 Funcionalidades
- Exibição de 5 níveis de alerta do reservatório.
- Associação de cores específicas para cada nível de risco (Vermelho, Amarelo, Verde, Ciano e Azul).
- Utilização de listas, funções e estruturas de repetição em Python.
- Restauração automática do estilo padrão do terminal após a execução.

## 🛠️ Tecnologias Utilizadas
- **Python 3**
- **Colorama** (Biblioteca externa para estilização de terminal)
